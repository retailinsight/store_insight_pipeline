# Issue Tracker Configuration

## Type
GitHub Issues

## CLI Tool
Uses the `gh` CLI for issue operations.

## Repository
Issues are tracked in the GitHub repository: `dantretailinsight/store_insight`

## Operations
- Create issues: `gh issue create`
- List issues: `gh issue list`
- Update issues: `gh issue edit`
- Add labels: `gh issue edit --add-label`
- Remove labels: `gh issue edit --remove-label`

## Notes
This configuration assumes the `gh` CLI is installed and authenticated.
